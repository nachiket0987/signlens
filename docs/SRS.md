# Software Requirements Specification (SRS) — SignLens

**Project Name:** SignLens  
**Author:** Nachiket Gadilohar  

---

## 1. Requirements
- **FR-DET-01**: Model MUST achieve > 90% Mean Average Precision (mAP@0.5) across target sign gestures.
- **FR-LAT-01**: Video frame inference latency MUST remain < 33ms for 30 FPS playback.
